# 06 新增管线
适用人员：有管网编辑授权的运维人员。开始前准备 WGS84 坐标、分区 ID、材质和管径。

@figure pipe-editor|图 6-1 新增管线。①新增管线页签；②基础信息；③地图取点工具；④坐标行；⑤提交管线。

1. 图中①确认当前是“新增管线”。自动生成的名称、材质、管径和分区 ID 都可以修改；分区 ID 必须从“分区管理”核对，不能直接使用默认值 2。
2. 图中②填写管线名称、材质、管径和分区 ID，展开“高级字段”可调整国家代码、坐标系、管线类型、形状和状态。
3. 图中③点击“地图点选中”后依次单击地图添加节点；可用“撤销上一点”“清空节点”“完成绘制”修正。第一个有效点会定位地图，后续点只更新预览。
4. 图中④按“经度、纬度”填写，范围分别是 -180 至 180 和 -90 至 90；至少两个有效点才显示预览线，最后一个空行不提交。
5. 图中⑤核对走向、坐标和交叉提示后点击“提交管线”。出现自身非相邻线段交叉或与正式管线真实交叉时，先修改坐标，不能强行提交。

结果核对：提交前页面只保留草稿，不发送创建请求；提交成功后用“管网图层”重新查询管线数量和走向。失败时保留草稿，不要重复新建同一条管线。

# 07 新增设施
适用人员：有设施录入授权的运维人员。设施可以独立提交，不会自动建立与管线的后台关联。

@figure facility-editor|图 7-1 新增设施。①新增设施页签；②添加设施；③阀门、消防栓、泵；④提交设施。

1. 图中①确认当前是“新增设施”，并核对分区 ID。
2. 图中②点击“添加设施”，同一页面可以连续添加多个设施；每个设施单独填写和删除。
3. 图中③选择“阀门、消防栓、泵”。图标只表示设施类型，最终以表单中的“设施类型”为准。
4. 图中④填写完成后点击“提交设施”。成功一项就从待提交列表移除；失败项保留原表单和错误，可单独重试。

@figure facility-form|图 7-2 设施表单。①类型、编号、名称和管径；②经纬度；③提交。

1. 图中①核对设施类型；设施编号默认自动生成，可直接修改；名称可留空，管径按毫米填写，没有资料时按要求填 0。

结果核对：提交后用“管网图层”的设施显隐和数量核对结果。管线成功但设施失败时，不要重建管线，只修改并重试失败设施。

# 46 常见问题与操作底线
## 46.1 看不到菜单或页面
先确认账号角色和分区，再让管理员检查菜单权限编码与页面路径。不要借用管理员账号代替日常账号。

## 46.2 查询没有数据
先清空设备编号和状态，放宽时间范围，再点查询。注意页面筛选的是创建时间、采样时间还是报警时间。加载中的 0 不是最终结果。

## 46.3 地图空白或管线不显示
中文界面使用腾讯地图，英文界面使用 Google 地图。先等待地图服务加载，再检查管网图层开关、分区筛选和“数据不完整未显示”提示。切换语言或供应商时不要连续拖动草稿设施。

## 46.4 保存失败或设施部分失败
保留当前表单和错误提示。管线失败时不会继续提交设施；管线成功而设施失败时，只重试失败设施，不要重复创建管线。

## 46.5 草稿与离开
有草稿时切换菜单会出现“还有未保存的管线草稿”。取消留在当前页；红色“否，放弃”丢弃草稿；是，保存会先提交并等待结果。刷新浏览器或退出登录不保证草稿恢复。

## 46.6 三条操作底线
1. 查看详情不等于提交；只有保存、确认创建、派单、保存处理或下发指令才可能改变业务状态。
2. 报警颜色、算法曲线、疑漏等级和模拟波形只用于辅助研判，不能代替现场复核。
3. 提交时等待加载完成；失败后先查询是否已经生成记录，再决定是否重试，避免重复工单、重复设施和重复指令。

## 46.7 报障时需要提供
报障时提供菜单名称、页面路径、账号、设备编号、时间范围、错误提示和截图。
